# K1SW 数据看板

基于 uni-app (Vue3) 跨端工程，支持 App / 微信小程序 / H5 三端，实现销售线索数据看板与客户跟进管理。

## 功能概览

- **账号密码登录**：统一登录接口，登录态本地持久化
- **首页数据看板**：蓝青渐变欢迎卡 + 分组卡片网格，展示各节点客户数量统计
- **左侧抽屉导航**：动态菜单列表，头部品牌区 + 关闭按钮 + 底部退出登录
- **客户列表页**：卡片式展示，支持筛选、分页加载、公司详情、跟进记录、点评操作

## 业务逻辑

### 登录流程

```
输入账号密码 → 调用 /k1swUserApi/login → 成功(code=1000) → 保存登录态 → 跳转首页
```

- 登录接口：`POST /k1swUserApi/login`
- 成功判定：`res.code === 1000`
- 登录态存储：本地存储键 `userKey`
- 请求头认证字段：`token`

### 首页看板流程

```
进入首页 → 加载菜单接口 → 默认选中第一条菜单 → 执行对应逻辑
```

**菜单逻辑：**
- 有 `path` 字段 → 跳转对应路径（携带 `name` 和 `id` 参数）
- 无 `path` 字段 → 在当前页面加载看板数据（调用 `/reportApi/companyFunnel`）

**看板数据结构：**
- 分组数据：`content` 数组，每个分组有 `name`（分组名）和 `value`（子节点数组）
- 子节点：每个子节点有 `name`（节点名）和 `value`（数量）
- 卡片颜色：按索引循环取色（青、蓝、绿、黄、红、紫）

### 客户列表页流程

```
从看板菜单跳转 → 进入列表页 → 自动加载客户列表（第1页）
```

**列表功能：**
- 卡片式布局，长文本超过 300 字自动折叠，可点击展开/收起
- 筛选：公司名称、销售员、开始/结束时间
- 分页加载：触底自动加载下一页，每页 20 条
- 更多按钮：弹窗展示公司详情（销售员、公司名称、公司介绍、知彼2内容）
- 跟进记录：弹窗展示沟通记录时间线
- 操作按钮：弹窗提交点评内容，提交前二次确认

### 退出登录流程

```
点击退出登录 → 弹出确认框 → 确认 → 清除登录态 → 跳转登录页
```

## 使用教程

### 1. 登录

1. 打开应用，进入登录页
2. 输入账号和密码
3. 点击登录按钮
4. 登录成功后自动跳转到首页数据看板

### 2. 查看看板

1. 首页顶部显示当前选中菜单名称
2. 下方按分组展示各节点客户数量统计卡片
3. 每个卡片显示：节点名称、数量
4. 点击有 `path` 的菜单跳转到对应节点的客户列表页

### 3. 使用左侧菜单

1. 点击左上角汉堡按钮，滑出左侧抽屉
2. 菜单列表从接口动态加载，显示所有可用功能模块
3. 点击菜单项：
   - 有 `path` 的模块 → 跳转到对应客户列表页
   - 无 `path` 的模块 → 当前页面更新看板数据
4. 点击右上角 ✕ 关闭抽屉

### 4. 客户列表管理

1. 进入列表页，自动加载第一页数据
2. 点击右上角筛选按钮，设置筛选条件后点确定
3. 下滑到底部，自动加载下一页
4. 点击卡片右上角"更多"按钮，查看公司详情
5. 点击"跟进记录"，查看沟通记录时间线
6. 点击"操作"按钮，提交点评内容

### 5. 退出登录

1. 打开左侧抽屉
2. 点击底部红色"退出登录"按钮
3. 确认退出后自动清除登录态并跳转回登录页

## 页面路由

| 路由 | 说明 |
|---|---|
| `pages/login/index` | 登录页（默认启动页） |
| `pages/index/index` | 首页数据看板 |
| `pages/list/index` | 客户列表页（从看板菜单跳转） |

## 接口列表

| 接口 | 方法 | 说明 |
|---|---|---|
| `/k1swUserApi/login` | POST | 登录接口 |
| `/k1swMenuApi/menulist` | GET | 菜单列表接口 |
| `/reportApi/companyFunnel` | GET | 公司漏斗看板数据 |
| `/contaceApi/contactList` | GET | 客户列表（分页） |
| `/contaceApi/moreContactList` | GET | 跟进记录详情 |
| `/contaceApi/companyInfo` | GET | 公司详情 |
| `/contaceApi/reviewContact` | POST | 提交点评 |
| `/contaceApi/sellerList` | GET | 销售员列表 |

## 技术栈

- uni-app + Vue3
- 跨端：App / 微信小程序 / H5
- 网络层：基于 `uni.request` 通用封装
- 主色：`#2b6cb0` → `#14b8a6` 蓝青渐变
- 背景：`#f7f9fd` → `#edf1f7` 浅灰渐变

## 网络层特性

| 功能 | 说明 |
|---|---|
| 基础地址 | 手动切换，注释切换开发/生产环境 |
| 全局 loading | 默认开启，并发请求计数，可单独关闭 |
| 认证头注入 | `setAuthHeaderGetter` 动态注入 token 字段 |
| 参数序列化 | 自动过滤空值，GET 参数自动拼接 |
| 错误归一 | 网络错误统一包装成 `{code, msg}` 格式 |

## 运行

1. HBuilderX 打开工程
2. 运行到浏览器 / 微信开发者工具 / 手机模拟器
3. 微信小程序需在公众平台配置 request 合法域名
