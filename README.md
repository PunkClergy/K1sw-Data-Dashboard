# K1SW 数据看板

基于 uni-app (Vue3) 跨端工程，支持 App / 微信小程序 / H5 三端，实现客户数据看板与节点列表管理。

## 功能概览

- **账号密码登录**：统一登录接口，登录态本地持久化
- **首页数据看板**：蓝青渐变欢迎卡 + 分组卡片网格，展示各节点客户数量统计
- **左侧抽屉导航**：动态菜单列表，头部品牌区 + 关闭按钮 + 底部退出登录
- **节点列表页**：卡片式多字段展示，支持展开/收起、筛选、列设置、联系人查看、跟进记录、操作菜单

## 业务逻辑

### 登录流程

```
输入账号密码 → 调用 /k1swUserApi/login → 成功(code=1000) → 保存登录态 → 跳转首页
```

- 登录接口：`POST /k1swUserApi/login`
- 成功判定：`res.code === 1000`
- 登录态存储：本地存储键 `userKey`
- 每次进入页面自动校验登录态，未登录自动跳转登录页

### 首页看板流程

```
进入首页 → 加载菜单接口 → 默认选中第一条菜单 → 执行对应逻辑
```

**菜单逻辑：**
- 有 `path` 字段 → 跳转对应路径（携带 `name` 和 `id` 参数）
- 无 `path` 字段 → 在当前页面加载看板数据（调用 `/reportApi/companyFunnel`）

**看板数据结构：**
- 分组数据：`content` 数组，每个分组有 `name`（分组名）和 `value`（子节点数组）
- 子节点：每个子节点有 `name`（节点名）和 `value`（数量）
- 卡片颜色：按索引循环取色（青、蓝、绿、黄、红、紫）

### 菜单导航逻辑

```
点击左侧菜单 → 关闭抽屉 → 判断是否有 path
```

- 有 `path`：跳转对应页面路径，携带 `name` 和 `id` 参数
- 无 `path`：当前页面重新加载看板数据

### 退出登录流程

```
点击退出登录 → 弹出确认框 → 确认 → 清除登录态 → 跳转登录页
```

## 使用教程

### 1. 登录

1. 打开应用，进入登录页
2. 输入账号和密码
3. 点击登录按钮
4. 登录成功后自动跳转到首页数据看板

### 2. 查看看板

1. 首页顶部显示当前选中菜单名称
2. 下方按分组展示各节点客户数量统计卡片
3. 每个卡片显示：节点名称、数量、颜色标签
4. 点击任意卡片可跳转到对应节点的客户列表页

### 3. 使用左侧菜单

1. 点击左上角汉堡按钮，滑出左侧抽屉
2. 菜单列表从接口动态加载，显示所有可用功能模块
3. 点击菜单项：
   - 有对应页面的模块 → 跳转到对应页面
   - 看板类模块 → 当前页面更新看板数据
4. 点击右上角 ✕ 关闭抽屉

### 4. 退出登录

1. 打开左侧抽屉
2. 点击底部红色"退出登录"按钮
3. 确认退出后自动清除登录态并跳转回登录页

## 页面路由

| 路由 | 说明 |
|---|---|
| `pages/login/index` | 登录页（默认启动页） |
| `pages/index/index` | 首页数据看板 |
| `pages/list/index` | 节点列表页（从看板卡片跳转） |
| `pages/test/test` | 测试页面 |

## 接口列表

| 接口 | 方法 | 说明 |
|---|---|---|
| `/k1swUserApi/login` | POST | 登录接口 |
| `/k1swMenuApi/menulist` | GET | 菜单列表接口 |
| `/reportApi/companyFunnel` | GET | 公司漏斗看板数据 |
| `/api/customer/list` | GET | 客户列表 |

## 技术栈

- uni-app + Vue3 (Composition API)
- 跨端：App / 微信小程序 / H5
- 样式：SCSS + BEM 命名规范
- 主色：`#2b6cb0` → `#14b8a6` 渐变

## 运行

1. HBuilderX 打开工程
2. 运行到浏览器 / 微信开发者工具 / 手机模拟器
3. 微信小程序需在公众平台配置 request 合法域名
